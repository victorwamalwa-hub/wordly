## Three Lab Submissions in One Repo

This repository contains **three separate deliverables** for three different lab rubrics:

### 1. Wordly — Dictionary SPA
An interactive dictionary using the Free Dictionary API.

**Run it:** Open `wordly/index.html` in your browser.

**Features:**
- Search any English word (fetches from `dictionaryapi.dev`)
- Displays definition, part of speech, example usage, phonetic, synonyms
- Plays pronunciation audio (when available)
- Save/unsave words to `localStorage`
- Dark/light theme toggle (JavaScript DOM + CSS class manipulation)
- Graceful error handling for invalid words and network failures
